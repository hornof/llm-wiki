## Summary

[[anthropic]] (2026-10-22) donated the **Agent Skills open standard** ([[skill-md|SKILL.md]] folders plus scripts and reference files) to the **Agentic AI Foundation (AAIF)**, the Linux Foundation body it co-founded with Block and OpenAI. The name, logo, GitHub org and the agentskills.io domain go with it. This follows the earlier [[mcp|MCP]] donation, and Block's [[goose]] is also in AAIF.

## Key Claims / Takeaways

- **Adoption (Anthropic's figures):**
  - 70+ agent platforms have integrated it, including ChatGPT, Cursor, GitHub Copilot and VS Code.
  - 1M skills published.
  - ~280M skill installs.
- **Governance:**
  - Engineers from Anthropic, Google, OpenAI and others maintain it as individuals.
  - Lead maintainers: David Soria Parra and Mahesh Murag.
  - Planned: versioned releases, a formal proposal process, and security guidance for skill authors and installers.
  - Contributors don't need AAIF membership.
- No code donation is mentioned; it's the spec and the brand.
