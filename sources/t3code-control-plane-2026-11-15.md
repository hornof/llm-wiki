## Summary

T3 Code (github.com/pingdotgg/t3code, MIT) runs the coding agents already installed on a machine, including [[claude-code|Claude Code]] and [[codex|Codex]], behind one interface with desktop, web and phone clients. The brief listed it under repos worth watching. The wiki hadn't recorded it before. Read from the README and GitHub's repo metadata; not installed or tried.

## Key Claims / Takeaways

- **What it is:** *"T3 Code runs the coding agents on your machine and gives them one fast interface. Start a thread at your desk, then approve the next step from your phone."*
- **Which agents:** *"It works with Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro, Pi, Muse Code, fx, and any"* agent that speaks ACP.
- **No token resale:** *"T3 Code does not resell tokens. It drives the agents you are already signed in to."* Threads can switch models midway, and *"Let Claude hand a task to Codex."*
- **Git:** *"Each thread can work in its own worktree."* Commit, push and open a PR from the thread.
- **Traction:** 61,356 GitHub stars per the GitHub API on 2026-11-15 (the brief says "61.2k★"); the repo was created 2026-02-08. Stars alone are one signal.
- **For the owner:** this is the remote-approval workflow (approve an agent's next step from a phone) without changing agents, and across vendors. Relevant if you run Claude Code and Codex side by side. [Judgment.]
