## Summary

[[garry-tan]] announces hosted GBrain, their agent memory system, launched from the terminal at gbrain.io. Setup works by pointing any agent at the page, and the hosted version is managed Postgres with pgvector. The replies are mostly questions about what it stores and who can read it.

## Key Claims / Takeaways

- **Setup:** *"just point your agent (any kind, Claude Code, Codex, Muse, Grok Bot, OpenClaw, Hermes) at this"*.
- **What hosted means:** *"GBrain hosted = postgres with pgvector autoscaling for you."*
- **Replies:**
  - Privacy: *"I would want to know what it writes there and who else can read it."*
  - Architecture, unanswered in the thread: does the markdown repo stay the source of truth, with Postgres only as an index?
  - One user reports it *"not working for me"*, with a screenshot.
