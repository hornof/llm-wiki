## Summary

Mistral released the open weights of Le Chonk, which Techmeme (citing ZDNET) identifies as Mistral Large 4. Mistral pitches it for agentic coding and cyber defense. On 2026-10-06 Mistral had launched Large 4 on its API and promised the weights for 2026-10-27; Digg first saw the release on 2026-10-29. This page uses Digg's roundup of Mistral's X post, WIRED and Techmeme; Mistral's own post wasn't fetched.

## Key Claims / Takeaways

- **Coding rank (Mistral's claim):** *"Le Chonk ranks #1 on @cognition’s FrontierCode among open models"*. Also claims *"a new benchmark for Pareto efficiency on @artificialanalysis"*.
- **Cyber defense (Mistral's claim):** *"State-of-the-art in cyberdefense"*, tested by vendors including CrowdStrike, Cloudflare, Rubrik and Zscaler. No numbers in the post.
- **Name:** Techmeme: *"Mistral releases the weights for Mistral Large 4, or Le Chonk"*, and says it rivals GLM-5.3 on the Artificial Analysis Coding Agent Index.
- **WIRED's framing:** Mistral *"claims its latest release matches or outperforms even the best models from DeepSeek"* and Z.ai in coding and cybersecurity.
- **Distribution:** weights on Hugging Face, customizable with Mistral Forge.
- **The promised date slipped by about two days**, if Digg's first-seen time matches the release. Whether the open weights are the same model as the API version isn't stated.
