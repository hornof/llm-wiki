## Summary

An r/ClaudeAI post (2026-11-14) by u/Any-Reputation8118 about Abyssal Garden, a WebGPU underwater scene built with [[claude-fable-5|Claude Fable 5.2]] in [[claude-code|Claude Code]]. The scene is generated by code when the page loads, so the whole thing is a single HTML file under 100 KB. The useful part is the prompt, published in the repo (github.com/Noniv/abyssal-garden, MIT). It sets priorities and a frame-time budget, and it defines "done" as two verification gates: a separate critic subagent that sees only the renders, and GPU timing on a scripted fly-through. The prompt and README were fetched from GitHub. The code wasn't run, and the performance numbers are the author's.

## Key Claims / Takeaways

- **What it is:** *"one 97 KB HTML file with no images, 3D models, sound files or libraries."* The README says *"one 96 KB HTML file"*; the post doesn't explain the 1 KB gap. The seabed is sculpted on the GPU and decorated with *"about two million kelp leaves and plants"*, and the sound is synthesized with Web Audio.
- **How it was built:** *"The initial build came from one prompt in Claude Code"*. Follow-up prompts added the start menu, rock collision and the detail levels.
- **The prompt's structure** (prompt.txt):
  - Priorities in ranked order *"when they conflict"*: visual quality, then frame pacing, then bundle size.
  - Hard constraints: *"No Three.js/Babylon.js or other engines."* and *"Zero per-frame JS allocations (no GC stutter)."*
  - A measurable target on the author's own hardware: *"GPU frame time ≤ 11 ms average, no frame > 16.7 ms during a scripted 60 s fly-through."*
  - **A blind visual critic:** *"a separate subagent that sees ONLY the your renders, never your code or reasoning."* It gets *"6 fixed camera poses"* and a short recording of the fly-through to catch shimmer and popping, and Claude iterates until the critic reports nothing above "minor".
  - A stop condition: *"DONE WHEN: both verification gates pass."*
- **Time and plan:** *"The actual Fable 5.2 work was around 2-3 hours I think? But I'm just on a Pro plan and was hitting limits frequently, so it took me ~3 days."*
- **Performance (README, self-reported):** *"about 180 fps at 2560×1440 on an RTX 5070 Ti"*, and on a budget phone *"about 20 fps at 670×372 on Low"*.
- **The skeptical replies:** one commenter says *"There's no game here, it's just a tech demo"*, and another that procedural scenes like this *"has been done for decades now"*, citing the demoscene. A third points to .kkrieger, a *"Full 3d first-person shooter at around 95kb size"* from 2004. The thread also argued over whether the author can say "I built" it.
- **For the owner:** the prompt is a reusable template for any agent task whose output is judged by eye. Rank the priorities, give a numeric budget, have a critic that can't see the code review the output, and state when the task is done. It's the same pattern as the [[chrisjz-universe-atlas-fable-verification-2026-07-16|universe atlas]] (verification, not trust), packed into one prompt rather than a CI pipeline. [Judgment.]
