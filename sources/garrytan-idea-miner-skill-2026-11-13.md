## Summary

[[garry-tan|Garry Tan]] (2026-11-13) posts a free skill he wrote, Idea Miner, and frames it as a way for a personal agent to *"recursively self improve as you use it"*. The linked gbrain.io page (fetched; saved as `_raw/garrytan-idea-miner-skill-2026-11-13.txt`) has the whole skill. Each morning it reads the last 24 to 48 hours of meetings, notes and memory pages and proposes 3 to 6 things to build, usually new skills. The replies are more useful than the post: several ask what is allowed to write into the agent's memory. It's offered both as a standalone skill and as a hosted run on [[garrytan-gbrain-hosted-2026-10-29|GBrain]].

## Key Claims / Takeaways

- **The post:** *"What if your own personal agent could recursively self improve as you use it? You can. I made the idea-minder skill to do exactly that."*
- **What it does (gbrain.io):** *"Each morning, read what actually happened in the last 24 to 48 hours and turn it into 3 to 6 concrete things the person could build: a new skill, a new agent, a workflow, a piece of code, or an upgrade to a skill they already have. New skills come first."*
- **Grounding rules:** *"Every idea must point to something real. Never invent one."* It checks the existing skill list so nothing is pitched twice. *"If the last two days were quiet, say so in one line instead of making ideas up."*
- **It keeps its own history:** *"Save each run as a dated page in memory (idea-miner/YYYY-MM-DD)."* The next run compares against it to see which ideas moved, got built or went quiet.
- **Replies on memory hygiene:** one suggests the agent *"propose changes to its own notes as a diff you approve once a week. If it writes straight to memory, a month later it's treating some one-off thing you said in passing as a rule."* Another: *"if a web page or an email it reads can end up in the skill, someone else gets to teach your agent too"*. And: *"the hard part is the agent grading its own homework"*.
- **For the owner:** "self-improving" here means the agent proposes new skills from your activity; a human still builds them. The replies' diff-and-approve idea is how this wiki already works, with PRs instead of a weekly diff. [Judgment.]
